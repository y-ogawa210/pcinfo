ブラウザ上で動作する PCスペック診断ツール です。
CPU・メモリ・ネットワーク・バッテリーなどの情報を自動取得し、危険度・理由・確認すべき状況まで一覧で表示します。
さらに、複数項目を総合評価した スコア（A〜D） とコメントも表示します。
主な機能
- PC の主要スペックを自動取得
- OS / CPU コア数 / メモリ / GPU / 画面解像度 / 色深度 / ピクセル密度
- ネットワーク情報（回線タイプ・ダウンリンク速度・RTT・セーブデータモード）
- バッテリー残量・充電状態
- ブラウザ UA / 言語設定 / Cookie / HTTPS / WebGL 対応

- 危険度判定（安全・許容・注意・危険）
- CPU・メモリ・ネットワーク・バッテリーなどを個別に評価
- 「理由」「どんな時に注意すべきか」まで表示
- 総合スコア（A〜D）を自動算出
- CPU / メモリ / GPU / ネットワークの4項目から総合評価
- スコアに応じたコメントを表示
- 表形式で見やすく整理
- 各項目の説明付き
- 危険度は色分けで直感的に理解できる UI
